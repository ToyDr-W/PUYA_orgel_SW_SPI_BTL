# 🧸 PY32F002Aマイコン搭載 電子オルゴールプロジェクト (PUYA_orgel_SW_SPI_BTL)

安価でコストパフォーマンスに優れたPUYA半導体製マイコン「PY32F002A」を使用した、おもちゃ修理・マイコン換装用の電子オルゴールプロジェクトです。
音楽表現豊かなオルゴール演奏と、外部メモリの音源を高音質でコンカレントに音声再生します。

## 🛠️ 対象プロジェクト（2モデル）

マイコンのPWM出力を活用したBTL駆動に対応する2つのモデルを同梱する予定です。

* **`orgel_SW_F002A_8`**: 省スペースな8ピンパッケージ採用、スイッチ切り替えとBTL駆動を両立した小型おもちゃ向け。
* **`orgel_SW_F002A_16`**: 16ピンパッケージ採用、複数スイッチやセンサー制御、LEDなどを追加しやすく拡張性が高い。

## 🎵 本プロジェクトの特徴と魅力

### 🌟 おもちゃ修理への応用
開発者である「名張市つつじが丘おもちゃ病院」さまのブログでは、電源条件や曲選択、周辺制御など多岐にわたるカスタマイズに対応するファームウェア開発スキルの重要性が述べられており、本プロジェクトはその実践的なベースとして活用いただけます。詳細は該当ブログもご参照ください。

### 🎹 約180曲の楽曲群と表現力
* 童謡からクラシックまで約180曲から選択可能で、情操教育にも最適です。
* エンベロープやエフェクト制御により、豊かなオルゴール音を奏でます。

### 🌟 IMA-ADPCMによる音声再生
SPI接続のフラッシュメモリ（または内蔵）から、IMA-ADPCM形式の音声をコンカレントに再生できます。

### 📐 基板レイアウトの練習
ブレッドボード解説を省き、実際の基板パターン設計の実践例を報告しています。
